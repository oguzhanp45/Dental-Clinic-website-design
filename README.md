## 🌟 Proje Özeti

Bu proje, statik bir web sitesinin ötesine geçerek; kullanıcı tercihlerini hatırlayan, canlı veri çeken ve matematiksel hesaplamalar yapan **Front-End odaklı** bir uygulamadır. Herhangi bir framework kullanılmadan, **Saf (Vanilla) JavaScript** ile DOM manipülasyonu yetenekleri sergilenmiştir.

## 🚀 Teknik Özellikler

### 1. 🌍 Dinamik Dil Yönetimi (i18n)
* Sayfa yenilenmeden anlık **Türkçe / İngilizce** geçişi.
* Kullanıcının dil tercihi `localStorage` ile hafızada tutulur.
* Özel yazılmış JS modülü ile metinler ve `placeholder` içerikleri dinamik yönetilir.

### 2. 💱 API Entegrasyonu & Microapp
* **Frankfurter API** kullanılarak anlık döviz kurları (USD, EUR, GBP) çekilir.
* `Async/Await` yapısı ile veri işlenir ve tedavi maliyetleri yabancı para birimlerinde gösterilir.

### 3. 🌓 Tema ve UI Yönetimi
* **Karanlık (Dark) & Aydınlık (Light)** mod desteği.
* CSS Variables (`:root`) mimarisi ile merkezi renk yönetimi.
* Tamamen responsive (mobil uyumlu) Grid ve Flexbox yapısı.

### 4. 💰 Maliyet Hesaplama Motoru
* Seçilen tedavi türü, implant sayısı ve ek hizmetlere göre anlık fiyat hesaplayan JS algoritması.

## 🛠️ Kullanılan Teknolojiler

* **HTML5:** Semantik etiket yapısı ve SEO optimizasyonu.
* **CSS3:** Modern Grid/Flexbox düzeni, CSS Değişkenleri, Animasyonlar.
* **JavaScript (ES6+):** Fetch API, LocalStorage, DOM Manipülasyonu, Event Handling.
